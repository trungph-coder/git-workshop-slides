# Git cho Team Dev - slide workshop

Slide deck có animation cho workshop "Git cho Team Dev" (tài liệu gốc: Diện Nguyễn Duy).
Mỗi khái niệm Git (4 vùng làm việc, HEAD, fast-forward, merge vs rebase, reset, cherry-pick, worktree, hooks, 7 tình huống cứu nguy) có một animation dựng bằng anime.js.

Xem online: https://trungph-coder.github.io/git-workshop-slides/

## Điều khiển

- `→` / `Space`: slide tiếp, `←`: slide trước, vuốt ngang trên điện thoại
- `O`: tổng quan, `F`: toàn màn hình, `R`: phát lại animation
- URL theo slide: `#/12`
